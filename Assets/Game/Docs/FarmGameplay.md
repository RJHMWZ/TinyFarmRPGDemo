# 农场经营版本：玩法、架构与扩展指南

本轮将原有角色创建、共享设置、存档和 HUD 接入了可重复游玩的农场经营循环。游戏界面继续使用项目当前的英文语言规范；这份开发与操作文档使用中文。

## 设计依据与范围

- 《Stardew Valley》官方介绍：种植、采集、制作、技能成长和邻里关系相互支撑，而不是各自独立的菜单。https://www.stardewvalley.net/about/
- 《Sun Haven》官方商店介绍：农场经营与 RPG 任务、成长和人物关系相结合。https://store.steampowered.com/app/1432860/Sun_Haven/

参考的是玩法组织方式，不依赖或复制这些商业游戏的源代码、美术和剧情。当前提供单张地图上的经营闭环；没有将战斗、钓鱼、多人、婚恋、动物养殖等尚未实现的内容包装成已完成系统。

## 启动与第一轮操作

新存档会在 HUD 左上方持续显示 7 步“第一天”目标：选择锄头、开垦 3 格、播种 3 格、浇水 3 格、睡觉、首次收获和出货。进度直接读取真实经营计数并随存档保存，不需要打开任务日志。

完成三块田的种植和浇水后，第一次睡眠会且只会让最多 3 株已浇水的教程作物立即成熟。首次出货会自动完成教程，奖励 200 金币和 50 农场经验；后续作物恢复正常生长速度。

1. 正常从 `Boot` 或 `MainMenu` 运行，新建角色或加载现有存档，进入 `GameScene`。
2. 初始拥有 500 金币、锄头、水壶、斧头、镐和 15 颗防风草种子。
3. 使用 WASD 或方向键移动。到中央偏东的农田，数字 `1` 选锄头，靠近地块，鼠标点击该地块或按空格耕地。
4. 数字 `5` 选种子并播种，数字 `2` 选水壶浇水。每次成功操作消耗 2 体力；失败不消耗。
5. 到西北的 `HOME / SLEEP`，空格打开睡眠确认，然后选择 `SLEEP & SAVE`。当天浇过水的作物增长一天。
6. 防风草经过 4 个浇水日成熟。靠近后用任意选中物品交互即可收获。背包满时收获失败，地里作物保留。
7. 到北侧 `SHIPPING`，选择物品后出货；睡觉时结算金币并自动保存。
8. 到 `SEED SHOP` 补种子，购买食物与农场用品，继续经营。
9. 按 `Tab` 查看任务，达到目标后点击任务领取奖励。西侧村民可每日对话、送礼。

直接启动 `GameScene` 仍需要当前槽位已有存档，保持原项目的入口约定。不会偷偷创建或覆盖玩家档案。

## 操作速查

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD／方向键，支持原设置中的改键 |
| 使用工具／收获 | 鼠标左键，可按住连续处理相邻目标；空格与手柄南键处理人物面前目标 |
| 交互 | 鼠标右键或空格与商店、箱子、村民和床交互 |
| 选择快捷栏 | `1–9`、`0`、`-`、`=`，或鼠标滚轮 |
| 背包 | `I`，沿用设置中的背包改键 |
| 任务日志 | `Tab` |
| 系统菜单／返回 | `Esc` |
| UI 导航 | 方向键、确认键；手柄取消键返回 |

互动距离限制为 1.8 个世界单位。鼠标在 Gameplay 中保持可见；点击只作用于指针实际命中的目标，不再错误使用人物面前的另一个目标。鼠标位于 UI 上时不会穿透到地图使用工具，滚轮仍可切换快捷栏。背包中左键拿起／放下整组物品，右键快捷装备或食用；仓库右键转移整组，出货箱右键出货一件。关闭 UI 的同一帧不会再次触发世界交互。完整的主机手柄认证和各平台输入规范仍需后续验证。

## 已落地的业务规则

### 物品与背包

- 24 个背包格，前 12 格为快捷栏；工具每格 1 件，常规物品每格最多 99 件。
- 添加物品优先补现有堆叠，再找空格。容量不足时整体失败，不留下部分添加。
- 移动支持同类合并和异类交换。可把背包后 12 格中的物品装备到当前快捷格。
- 仓库同为 24 格；整组存入／取出检查容量后完成，不因目标背包满而丢物品。
- 食物恢复体力，体力已满时不会消耗。工具不允许出货或送礼。
- 本版本没有拖拽拆分、丢弃、装备属性和物品品质等级；避免出现未接业务的按钮。

### 耕种

- 地块状态：未耕／已耕、已浇水、种子 ID、生长天数、肥料、洒水器。
- 当天浇水，结算时才会增长；没浇水不会倒退。
- 下雨自动浇灌耕地，包括雨天新开垦的地块。
- 春季防风草、马铃薯；夏季番茄；秋季南瓜；四季胡萝卜保证冬季也有可种内容。
- 跨季后不适应该季节的作物枯萎并清空；胡萝卜可跨季保留。
- 番茄成熟后可重复收获，重新等待 2 个浇水日。
- 肥料在空耕地播种前施加，增加 1 个收获物。一次性作物收获后消耗肥料。
- 洒水器永久放置在已耕地块上，每天清晨浇灌自身与上下左右四格，不跨行错误连接。
- 镐可清除没有作物、没有洒水器的空耕地，防止误删设备和作物。

### 经济与制作

- 商店按当前季节提供种子；购买前检查合法数量、总价、金币和背包容量。
- 出货是明确的“出货 1 件／出货整组”操作，先移除物品、记录成交单价，睡眠后付款。
- 每笔出货结算后清空，加载存档不会重复付款。
- 配方包括肥料、农场沙拉、洒水器、胡萝卜种子包；配方含产出数量、材料和等级门槛。
- 制作在背包副本上执行材料扣除与产物添加，全部成功后才提交。
- 对数量和金币乘法使用较宽整数检查，拒绝无效交易和溢出。

### 成长、任务与关系

- 农场等级 1–10，每 100 XP 提升一级；收获、采集、制作和任务可获得经验。
- 10 条目标涵盖耕地、播种、浇水、初次收获、出货、采集、制作、对话、送礼和收入。
- 任务前置链基于已领取奖励状态；奖励只能领取一次。
- 目标统计是生涯累计，即使任务尚未解锁，之前做过的行动也计入进度。
- 每位村民每天首次对话增加 20 好感；每天可送一份礼物，喜欢的物品 +80，其余可赠物品 +30。
- 好感上限 1000，记录每日交互日期。多次开关面板无法重复刷每日对话奖励。

### 时间、每日结算与保存

- 默认现实 7 秒推进游戏 10 分钟，06:00 开始，22:00 自动结束当天。
- 游戏暂停、设置窗口、背包和其他模态窗口打开期间，世界时间、体力与经营状态不会自动推进。
- 每日结算统一完成日期推进、天气选择、生长／枯萎、清晨灌溉、出货付款、体力恢复、回家和自动保存。
- 天气按已游玩天数确定，存取档不会重新抽取当日天气。冬季不生成雨天。
- 每 120 秒有效游戏时间自动保存；菜单可手动保存，睡觉后、系统暂停及退出时也会尝试保存。
- 保存失败会显示提示，并保留当前会话。菜单里的保存退出仍以保存成功为前提。

## 代码架构与依赖

```text
GameRoot / GameSession / SaveService（原有单一状态与持久化入口）
  └─ GameplayEntryPoint
      └─ FarmRuntime（场景生命周期、时间驱动、保存适配）
          ├─ FarmGame（会话级业务入口与事件）
          │   ├─ InventoryService（背包与仓库事务）
          │   ├─ FarmingService（地块、作物、资源刷新）
          │   ├─ FarmEconomyService（商店、出货、制作、食物）
          │   └─ FarmProgressionService（经验、任务、村民关系）
          ├─ FarmWorldView（地图、精灵、排序、相机）
          └─ FarmInteraction（输入、目标选择、距离检查）

UIService
  ├─ SettingsPanel（原有共享设置）
  └─ FarmHubPanel（预制体、缓存窗口、序列化视图引用）
```

- `FarmContent`：ScriptableObject 内容定义，持有稳定 ID、数值、配方、任务和精灵引用；不能把玩家进度写入它。
- `GameSaveData.farm`：地块、仓储、出货队列、计数器、资源恢复日期、村民每日交互、经验与体力。
- `FarmGame` 和各服务不依赖 GameObject、输入设备、UI、场景查找或磁盘；可用 EditMode 直接验证规则。
- `FarmRuntime` 将 Unity 的帧时间和场景玩家位置适配到业务及存档，不重复持有一份玩家状态。
- `FarmHubPanel` 只读状态并派发命令，不直接计算购买、制作和奖励规则。
- `GameplayHudController` 不再推进日历或累计游玩时间，避免两个时钟同时运行。
- 暂停仍由 `PauseService` 按所有者管理，输入仍由 `InputModeService` 管理；新系统没有直接改写 `Time.timeScale`。
- 世界变化通过 `FarmGame.Changed` 刷新，操作结果通过 `Feedback` 展示；每日结算通过 `DayEnded` 触发存档。
- 世界最近目标查询只扫描当前单图的少量交互对象；地图扩大后可以将查询换成空间索引，而不改变业务服务。

## 内容生产与替换素材

主资产：`Assets/Game/Resources/FarmContent.asset`。

1. 在 Inspector 中展开 `items` 替换 `icon`；展开 `crops` 替换 `stages`，按从种子到成熟的顺序排列。
2. 地图精灵由 `grass/soil/tree/rock/workbench/chest/bed` 引用；村民默认复用现有角色的皮肤、服装、眼睛和头发分层，设置 `portrait` 可改用一张完整站位角色图。
3. 修改物品买卖价、堆叠上限、食物恢复值、作物季节、天数、配方材料、任务奖励，不必修改 UI 代码。
4. 新物品使用新的唯一字符串 ID。已发行 ID 是存档契约：替换贴图、显示名不会影响存档；重命名 ID 必须增加显式迁移。
5. 新作物增加种子物品、产出物品和作物定义三部分。季节位掩码：春 1、夏 2、秋 4、冬 8，0 表示四季。
6. `Tools > Tiny Farm > Validate Farm Content` 检查重复 ID、悬空引用、数值、配方材料重复和任务循环依赖。
7. `Tools > Tiny Farm > Build Farm Content` 只创建缺失资产并补齐 UI 注册，不覆盖已调好的数值与美术，也不保存当前打开的场景。

生成器将自带精灵复制成中心轴心的子资产，避免原图集不同轴心导致地图错位；不修改第三方源素材。新增农场面板位于 `Assets/Game/Prefabs/UI/FarmHubPanel.prefab`，通过 `UIPanelCatalog` 注册为缓存 Window，打开时暂停游戏。

## 存档演进

当前信封版本升级为 v4。读取 v3 时保留角色、位置、金币、背包、日期和原任务字段，新增农场状态、满体力及空仓库。v2 及更早的角色档案继续走原有导入路径。存档仍由原 `SaveService` 做临时文件写入、原子替换和备份恢复。

每个地块按 8×5 固定索引存储；本版本暂不支持任意扩地。未来扩大地图时，应把地块改为稳定世界坐标／地图 ID，并增加 v4 到下一版本的显式迁移，不能简单调整数组长度。

## 验证与回归

`FarmGameplayTests` 验证库存事务、仓储、金钱边界、作物生长、满包收获、跨季、灌溉边界、肥料、体力、制作回滚、任务幂等、社交日限制、采集刷新、跨年、睡眠付款、完整种收售闭环和旧档迁移。

`FarmLoopPlayModeTests` 加载真实场景，验证地图目标、面板暂停与恢复、UI 购买、双向仓储、睡眠存档及场景重载。测试把存档目录切换到独立临时目录，避免覆盖玩家存档。设置 `TINYFARM_FARM_SCREENSHOTS` 环境变量可输出地图、日志、商店和 4:3 背包渲染图；需要有图形设备的 Unity 进程。

执行原有 `Tools/CI/Run-UnityValidation.ps1` 可运行 EditMode、PlayMode 和项目健康检查。构建前校验现在也包含农场内容。首次没有生成内容资产的干净项目，可先通过 Unity `-executeMethod FarmContentBuilder.Build` 创建。

## 商业化后续仍需完成

- 资产级地图美术编排、人物动作／工具动作／命中特效、环境音效、音乐、天气粒子和 UI 动效。
- 战斗、钓鱼、动物、房屋建设、NPC 行为树／日程／寻路、长篇剧情与多场景世界。
- 制作队列、物品品质、装备、仓库扩容、商店库存与节日经济。
- 完整本地化与中文字体策略、键鼠与全手柄体验、无障碍、平台认证。
- 长时间压力测试、目标硬件性能预算、发布构建、崩溃上报、平台成就和云存档。

这些是后续明确的生产工作，并非本版本中已经实现的隐藏功能。本版本的目标是提供可验证、可替换内容、可持续扩展的农场经营基础。
