# 农场玩法优化记录

本轮针对种植、背包、仓库和出货这条日常循环进行优化。交互参考《星露谷物语》的快捷转移、同类物品归堆和最近一次出货取回；沿用项目现有素材与面板，主菜单素材和文本没有改动。

## 玩家可用的新操作

| 界面 | 操作 | 行为 |
| --- | --- | --- |
| 背包 | ORGANIZE | 合并并整理第 13–24 格，保留前 12 格快捷栏和当前选择 |
| 背包 | Shift + 左键 | 将物品装备到当前快捷栏格子；点击快捷栏内物品则选中该格 |
| 仓库，存入视图 | QUICK STACK | 将背包中仓库已有的同类物品归堆；保留工具，容量不足时剩余物品留在背包 |
| 仓库，取出视图 | ORGANIZE | 合并并整理仓库全部格子 |
| 仓库 | Shift + 左键／右键 | 转移整叠物品 |
| 仓库 | Shift + 右键 | 转移半叠物品，奇数向上取整；空间不足时取消整个操作 |
| 出货箱 | UNDO LAST | 取回最近一次放入的一件或一叠物品；不能连续取回更早的出货 |

出货取回仅在睡觉结算之前有效。背包放不下时物品仍保留在出货箱，腾出空间后可重试。最近出货的可取回状态会随存档保存，旧存档缺少该字段时按不可取回处理。撤回会扣回本次出货计数，已经领取的一次性任务／教学奖励不回收，也不能重复领取。

## 逻辑修复

- 播种、施肥、放置洒水器、吃东西、出货和送礼按选中的格子扣除，避免消耗快捷栏或其他同类物品格子。
- 合成仍按物品 ID 跨格取材料，并用副本保证材料和产物同时提交。
- 整理保留旧存档中的未知物品；转移失败不会丢失物品。
- 鼠标位于 UI 上时滚轮不切换快捷栏；打开面板／暂停时清除农田拖动操作记录。

## 代码结构

调用路径为 `FarmHubPanel / FarmInteraction → FarmGame → 各领域服务 → Save`。

- `InventoryService`：格子扣除、容量计算、合并整理、原子转移。
- `FarmInventoryActions`：装备、背包／仓库整理、整叠／半叠转移、同类归堆。界面不再直接处理这些规则。
- `FarmEconomyService`：出货、撤回、隔夜结算。
- `FarmGame.StateChanged`：按 `Inventory / World / Progression / Clock / Hotbar` 通知；保留原有 `Changed` 事件以兼容旧订阅者。新增命令必须通过 `FarmGame.Execute` 发布变化；默认 `All`，明确只改背包的命令可指定更小范围。
- `FarmWorldView`：只响应 `World` 变化；时钟、快捷栏和面板物品操作不再刷新全部农田渲染状态。昼夜光照仍在原有 `LateUpdate` 更新。
- `FarmContent`：物品、作物、配方、任务和 NPC 使用稳定 ID 索引。编辑器修改后自动重建；代码替换定义数组后需调用 `RebuildIndex()`。
- `FarmInteraction`：缓存快捷键和相机，目标距离比较采用平方距离。

存档保持现有 v4 格式，仅新增可选字段 `lastShipmentRecoverable`，不更改物品 ID 或已有农田结构。

## 验证

新增回归覆盖：指定格子消耗、失败无变更、快捷栏保护、未知物品保留、部分容量归堆、半叠转移、出货撤回及重载、撤回计数、变化事件范围，以及面板真实按钮操作。

Unity 测试与工程健康检查结果保存在 `Artifacts/FarmOptimization`。测试在独立验证副本中执行，面板测试使用临时存档目录。

本轮结果：EditMode 51/51、PlayMode 14/14，工程健康检查退出码 0。截图检查覆盖 1024×768、1280×720 和 1600×900；通过 MCP 刷新当前项目后，Unity 编辑器控制台错误条目为 0。

## 后续扩展方向

现有背包、仓库、出货仍共享一个面板。后续可以在保持领域服务不变的前提下，将页面拆成独立视图，再逐步增加仓库双栏布局、睡前收入明细和种子成熟日期提示。本轮没有引入新的技能、节日、动物或生产机器系统。
